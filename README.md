# NESCIO — versão GitHub Pages

Esta é uma primeira versão estática do NESCIO, preparada para GitHub Pages.

## Ficheiros

- `index.html` — estrutura e textos
- `style.css` — design responsivo
- `script.js` — pequenas interações

## Publicar no GitHub Pages

1. Cria um repositório no GitHub, por exemplo `nescio`.
2. Envia estes três ficheiros para o repositório.
3. Vai a **Settings → Pages**.
4. Em **Build and deployment**, escolhe **Deploy from a branch**.
5. Escolhe `main` e `/ (root)`.
6. Guarda.

Depois o site ficará disponível no endereço do GitHub Pages.

## Imagens

Os blocos cinzentos são placeholders propositados. Quando quiseres, substitui-os pelas fotografias reais em `/images` e altera os elementos `.image-placeholder` para `<img>`.
